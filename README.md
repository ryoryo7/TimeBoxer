## 概要

TimeBoxerは、タスクに時間枠（タイムボックス）を設定し、集中して作業を行うための時間管理アプリです。タスクの作成、カウントダウンタイマー、実行ログの記録、グラフによる可視化などの機能を提供します。

## 主な機能

### タスク管理
- タスクの追加・編集・削除
- 優先順位のドラッグ&ドロップによる並べ替え
- 想定時間の設定
- 対象日の設定
- 完了/未完了の切り替え

### カウントダウンタイマー
- プリセット時間（5分/10分/30分/60分）
- カスタム時間設定（1〜999分）
- タスク選択時の想定時間自動入力
- 開始/停止/クリア機能
- 完了時の通知音
- バックグラウンドでの動作継続
- リロード後のタイマー復元

### 実行ログ
- タイマー完了時の自動記録
- 日付範囲によるフィルタリング
- ログのインライン編集
- 超過時間の自動計算
- CSV出力

### メモ帳
- 最大10個のタブ形式メモ
- タブの追加・削除・名前変更
- 折りたたみ機能

### データ可視化
- タスク別時間割合の円グラフ
- 期間フィルター（今日/今週/今月/全期間）
- 活動タイムライン表示

### データ同期
- Google スプレッドシートとの連携
- 自動同期（起動時・データ変更時）
- オフラインモード対応

## 動作環境

### 必須
- モダンブラウザ（Chrome、Firefox、Safari、Edge の最新版）
- JavaScript有効

### 開発環境（オプション）
- Node.js 18.x 以上
- npm 9.x 以上

## セットアップ

### 基本的な使用（ブラウザで開くだけ）

1. リポジトリをクローンまたはダウンロード
```bash
git clone https://github.com/yourusername/TimeBoxer.git
cd TimeBoxer
```

2. `index.html`をブラウザで開く
```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

### 開発環境のセットアップ

1. 依存パッケージをインストール
```bash
npm install
```

2. 開発ツールの確認
```bash
# コード整形、Lint、テストを一括実行
npm run all
```

### Google スプレッドシート連携のセットアップ

Google スプレッドシートとの連携を有効にする場合は、`SETUP_GUIDE.md`を参照してください。

## 起動方法

### 方法1: ブラウザで直接開く（最も簡単）

`index.html`をダブルクリックするか、ブラウザにドラッグ&ドロップしてください。

### 方法2: ローカルサーバーで起動（推奨）

```bash
# Python 3の場合
python -m http.server 8000

# Node.jsの場合（npx使用）
npx serve .
```

その後、ブラウザで `http://localhost:8000` にアクセスしてください。

### 方法3: VS Code Live Server

VS Codeの「Live Server」拡張機能を使用している場合、`index.html`を右クリックして「Open with Live Server」を選択してください。

## 使い方

### 1. タスクを追加する

1. 「タスク名」にタスクの名前を入力
2. 「優先順位」に数値を入力（小さいほど上位）
3. 「想定時間」に予定時間（分）を入力
4. 「対象日」を選択
5. 「追加」ボタンをクリック

### 2. タイマーを使う

1. 「対象タスク」からタスクを選択（想定時間が自動入力されます）
2. 必要に応じて「カスタム時間」を調整
3. 「▶ Start」ボタンをクリックしてタイマー開始
4. タイマー終了時に自動でログが記録されます

### 3. 実行ログを確認する

- デフォルトで今日のログが表示されます
- 「−1日」「+1日」ボタンで日付を移動
- 「全期間」ボタンで全ログを表示
- ログをクリックして編集可能

### 4. タスクの並べ替え

未完了タスクはドラッグ&ドロップで優先順位を変更できます。タスク行をドラッグして、移動したい位置にドロップしてください。

### 5. メモを使う

- 右上のメモセクションをクリックして展開/折りたたみ
- 「+」ボタンでタブを追加（最大10個）
- タブ名をダブルクリックで名前変更
- メモ内容は自動保存されます

### 6. グラフとタイムラインを見る

- 「タスク別時間割合」で作業時間の内訳を確認
- 「活動タイムライン」で時間軸上の作業を可視化
- 期間を選択してフィルタリング可能

## データ保存について

### ローカルストレージ

- データはブラウザのLocalStorageに保存されます
- ブラウザのキャッシュをクリアするとデータが消える可能性があります
- 定期的なCSVバックアップを推奨します

### Google スプレッドシート連携

- 設定済みの場合、データは自動的にGoogle スプレッドシートに同期されます
- オフライン時はローカルストレージのみで動作します
- 詳細は`SETUP_GUIDE.md`を参照してください

### バックアップ方法

1. **タスク + ログのCSV出力**: タスクセクションの「📥 CSVエクスポート」ボタン
2. **ログのみのCSV出力**: 実行ログセクションの「📥 ログCSV出力」ボタン

## トラブルシューティング

### タイマーが動かない

1. ブラウザのJavaScriptが有効か確認してください
2. コンソール（F12）でエラーを確認してください
3. ページをリロードしてください

### データが消えた

1. ブラウザのキャッシュをクリアしていないか確認してください
2. Google スプレッドシート連携を設定している場合、スプレッドシートを確認してください
3. 別のブラウザや端末からアクセスしていないか確認してください

### 同期が失敗する

1. インターネット接続を確認してください
2. Google Apps ScriptのURL設定を確認してください
3. コンソール（F12）でエラーを確認してください

### ドラッグ&ドロップが効かない

- 完了済みタスクはドラッグできません
- タスク名のテキスト部分をドラッグすると選択モードになります
- タスク行の他の部分（優先順位、時間など）をドラッグしてください

### 通知音が鳴らない

1. ブラウザの音声自動再生設定を確認してください
2. 「成功音.mp3」ファイルが存在するか確認してください
3. 一度ページ上でクリックしてからタイマーを開始してください（ブラウザの自動再生ポリシー対策）
